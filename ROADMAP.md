# Roadmap

Implemented: local assets/batch workflow; manual sequence revisions; reference constants; editable difficulty functions; frequency/movement trajectory; reference-timing arc paths and endpoint pass; ArcCreate previews; consolidated CSV; public synthetic fixtures and handover guides.

Near term: native acceptance checks, clearer stage freshness and marker meanings, drag-based path correction, batch arc-only reruns in GUI, portable workspace export/import, better diagnostics and minimal reproductions.

Research: reviewed benchmark passages; timing/reachability mechanics; interaction between arc choices and assignment; timestamp-rate Peak; normalization against an explicit reference corpus; held-out evaluation.

Future: local preference tuning/training with reviewed alternatives; 2D occupancy heatmap; chart radar; hand-trip and block metrics. These are proposals, not shipped features or promised dates.
