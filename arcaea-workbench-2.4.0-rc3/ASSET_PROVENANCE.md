# Asset provenance

| Included item | Origin and scope |
|---|---|
| app/, core/ Python | Project implementation developed through user direction, AI-assisted coding and iterative review |
| docs/, repository guides | Rewritten project documentation for independent users/maintainers |
| examples/workbench-demo_2.aff | Newly authored synthetic chart; no game chart or audio copied |
| examples/workbench-demo_2.sequence.json | Generated from that synthetic chart by the bundled allocator |
| defaults/songlist.json and chart-constants.csv | Synthetic schema examples; constant 1.0 is fictional |
| Other defaults and tests | Project configuration and regression fixtures; heuristic assumptions are not certified mechanics |

The public archives omit the earlier Black Mind/Aegleseeker/Arcana Eden chart assets, supplied game songlist, copied wiki constant table, personal review database and earlier private validation reports. Existing private working copies are not changed by this packaging step.

No audio, artwork, game binaries or dependency distributions are bundled. Users supply real chart collections and metadata themselves. Arcaea and ArcCreate names identify interoperability targets; this is an independent project.
